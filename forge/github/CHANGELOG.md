## [0.5.0]

### Changed

- The plugin is now a forge, pipelinegen's new name for the kind connector: it lives in `forge/github`, its program is `github-forge`, its module `github.com/sideways-works/pipelinegen-plugins/forge/github`, and `describe` answers kind `forge`, which pipelinegen v0.6.0 requires. Its releases are tagged `forge/github/vX.Y.Z`; the last of `connector/github` was v0.4.0, and this release continues from there
